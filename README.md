## Agreed MVP direction

- React + TypeScript + Vite; no Streamlit.
- White/lavender canvas with purple accents and dark-purple sidebar.
- Upload creative images + CSV, validate columns, analyze available metrics, inspect evidence-backed findings, export CSV.
- Client-side-first implementation for the time-boxed MVP; optional backend only if required.
